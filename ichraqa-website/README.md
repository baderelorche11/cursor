# منصة أكاديمية إشراقة وعي الدولية للكوتشينغ

> معًا لمحاربة التفاهة — نلتقي لنرتقي — والفائدة للجميع

**Ichraqa Academy Management Platform** هي النسخة الأولى (MVP) من المنصة: موقع عام احترافي بالإضافة إلى لوحة تحكم كاملة لإدارة الأكاديمية.

## التشغيل

الموقع ثابت بالكامل ولا يحتاج إلى أي تثبيت:

```bash
cd ichraqa-website
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

ويمكن نشره مباشرة على Firebase Hosting أو GitHub Pages أو Netlify.

## ما تم إنجازه

**الموقع العام:** الرئيسية، من نحن / الرؤية / الرسالة / الأهداف، الهيكل التنظيمي، الإدارة، الكوتشز، اللجان (11 لجنة بحقائبها)، الفرق، المشاريع، التكوين، المكتبة، الأخبار، الفعاليات، TikTok Live، التحقق من الشهادات (بالرقم مع رمز QR)، استمارة الانضمام الكاملة، التواصل، وبنية الموقع.

**لوحة التحكم `/dashboard`:**
- Academy Dashboard: النقاط، المستوى، النشاط، المهام، الترقية القادمة، الفريق واللجنة، الإعلانات
- بطاقة إشراقة وعي (الملف الشخصي)
- محرك النقاط: اقتراح ← مراجعة ← اعتماد ← الرصيد ← سجل التدقيق، ويمنع اعتماد الشخص لنقاطه أو لاقتراحه
- الترقية: النقاط + النشاط + الالتزام + الدورة + تقييم المسؤول
- المهام (Kanban): جديدة / قيد التنفيذ / بانتظار المراجعة / مكتملة / متأخرة
- الفرق، اللجان، المشاريع، الاجتماعات والمحاضر والحضور، التكوين، الشهادات، البثوث، التقارير، الإعلانات، الإشعارات
- الإدارة: Command Center، طلبات الانضمام (قبول / معلومات إضافية / رفض ثم إنشاء الحساب)، الأعضاء، المالية (للمخولين فقط)، سجل التدقيق، Academy Settings (نقاط الأنشطة، الرتب، شروط الترقية، أنواع العضوية)
- نظام صلاحيات RBAC بعشرة أدوار
- العربية (RTL) مع الفرنسية والإنجليزية، ووضع ليلي، وتصميم متجاوب مع الهاتف

## البنية

```
ichraqa-website/
├── index.html

├── js/data.js         البيانات الأولية (قابلة للتعديل من الإعدادات)
├── js/store.js        طبقة البيانات + الصلاحيات + محرك النقاط + التدقيق
├── js/ui.js           أدوات الواجهة
├── js/i18n.js         اللغات
├── js/public.js       صفحات الموقع العام
├── js/dashboard.js    لوحة التحكم
├── js/app.js          التوجيه والهيكل
├── assets/logo.svg    شعار مؤقت (يُستبدل بالشعار الرسمي)
└── firestore.rules    مسودة قواعد الأمان لـ Firestore
```

## ملاحظة مهمة قبل الإطلاق الفعلي

هذه النسخة تحفظ البيانات في متصفح المستخدم (localStorage) لأغراض العرض والتجربة، وتسجيل الدخول فيها تجريبي فقط. للإطلاق الحقيقي:

1. إنشاء مشروع Firebase وتفعيل **Authentication** و **Firestore** و **Storage**.
2. إعادة كتابة `js/store.js` فقط لتستعمل Firebase، فكل الصفحات تمر عبره.
3. نشر `firestore.rules`، وتخزين الأدوار كـ custom claims، وكتابة سجل التدقيق عبر Cloud Functions.
4. استبدال `assets/logo.svg` بالشعار الرسمي، ورمز QR الزخرفي بمولّد QR حقيقي.

المراحل التالية حسب الوثيقة: التكوين المتقدم ← الشهادات ← المالية (Stripe) ← المشاريع المتقدمة ← التقارير المتقدمة.
